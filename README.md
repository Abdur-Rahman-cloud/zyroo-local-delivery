# ZYROO Local Delivery

A responsive React frontend prototype for a local delivery platform, built as part of the ZYROO Frontend Development Internship.

## Features

* Home page
* Dashboard with delivery statistics
* Orders management
* Order details and status timeline
* Customer delivery tracking
* Responsive design
* Mock delivery data

## Tech Stack

* React.js
* Vite
* React Router
* CSS
* JavaScript

## Run Locally

<!-- bash -->
npm install
npm run dev
